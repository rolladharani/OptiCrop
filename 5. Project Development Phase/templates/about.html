Project Overview

Revolutionizing Farming with AI Intelligence

The OptiCrop project aims to develop an advanced software system that utilizes data-driven insights to optimize agricultural production for different crops. By integrating key environmental factors, OptiCrop provides intelligent recommendations to farmers for maximizing yields and resource efficiency.

The knowledge and insights gained through the OptiCrop project can be utilized by agricultural researchers, policymakers, and stakeholders to advance the understanding of crop–environment interactions and inform the development of evidence-based agricultural strategies.

Machine Learning

AI Techniques Powering OptiCrop

K-Means Clustering

Applied to identify patterns and group similar agricultural conditions. The Elbow Method is used to determine the optimal number of clusters by analyzing WCSS values, revealing 4 distinct crop environmental groups.

Unsupervised Learning Pattern Recognition Elbow Method

Logistic Regression

The primary classification algorithm trained on 2,062 preprocessed records to predict the most suitable crop from 22 categories. Achieves ~94–96% accuracy on held-out test data with comprehensive F1 scores.

Supervised Learning Multi-class Classification 96% Accuracy
